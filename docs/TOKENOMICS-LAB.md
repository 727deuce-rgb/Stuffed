# Product direction: Tokenomics Lab

Stuffed is becoming a hands-on token design simulator, not a passive document store.

## Core promise

> Build it. Break it. Fix it before launch.

Users can change supply, allocations, projected holders, and token consumption to see educational model outputs. The lab is intentionally labeled a simulation: it is not a price forecast, investment advice, audit, or safety guarantee.

## Why users care

A creator can find concentration, runway, allocation, and control problems before spending money on a contract or presenting a project to a community. The visual feedback makes token design understandable and shareable.

## Next product slices

- Connect the lab to saved projects.
- Add scenario save/compare and share links.
- Add an interactive admin-permission risk panel.
- Add a white-paper preview generated from the selected scenario.
- Add a testnet deployment preview only after the contract template is audited.
